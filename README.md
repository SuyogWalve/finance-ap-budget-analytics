# Finance Analytics: AP Ageing, Budget vs Actual, Expense Claims

Practice project on a synthetic finance dataset using SQL Server and Power BI.

**What I built**
- SQL views for AP ageing, budget vs actual and expense claims
- Power BI star schema (4 dimensions, 3 facts) with DAX measures
- 4 report pages: Overview, AP Ageing, Budget vs Actual, Claims, plus Key Insights

**Key findings**
- 50.3% of payables (21.69M) are over 90 days old
- Actual spend is 27.8% over budget; 51.2% of spend had no budget line
- Claims are approved in 5.4 days but take 23.4 days to reimburse

**Tools:** SQL Server, Power BI, DAX
